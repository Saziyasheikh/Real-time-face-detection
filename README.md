## 🎭 Real-Time Face Detection Using Python & OpenCV

A simple and powerful Real-Time Face Detection project built using Python and OpenCV.
This project detects human faces through a webcam and highlights them with a rectangle in real time.

## 🚀 Features
📷 Real-time webcam face detection

🧠 Uses OpenCV Haar Cascade Classifier

⚡ Fast and lightweight

🎨 Simple and clean interface

👨‍💻 Beginner-friendly Python project

## 🛠️ Technologies Used

Python

OpenCV

VS Code

## 📦 Required Library

Install OpenCV using:

pip install opencv-python

## 📸 Output

Webcam opens automatically

Detects faces in real time

Draws a green rectangle around faces
